# 🧭 Bottom Navigation App

A **Flutter app** demonstrating the use of a **Bottom Navigation Bar** with **three separate screens** — 🏠 Home, 📝 Tasks, and 👤 Profile.  
Built using **Flutter**, **Dart**, and **Material 3**, this project follows a clean folder structure and modern UI design principles.

---

## 🚀 Features

- 📱 Three separate screens — **Home**, **Tasks**, and **Profile**  
- 🎨 **Material 3 UI** for a modern, minimal, and elegant interface  
- 🧩 Uses **NavigationBar (Material 3)** instead of the old BottomNavigationBar  
- 🌈 Custom **color scheme** (soft violet-blue theme)  
- 🧱 Clean code & folder structure for scalability
